# Flickday hybrid raster proofs — round 2

Status: visual exploration; not final production artwork.

This round keeps the full wordmark as a raster proof so the custom glyph can be judged optically before another vector rebuild.

- `aperture-i-raster-proof-v2.png` uses a six-blade mechanical iris with curved, overlapping blades.
- `play-d-raster-proof-v2.png` returns to the softer play-d relationship from the original Firefly lockup.
- `comparison-board.png` presents both proofs at equal scale.

The earlier files under `flickday-assets/brand/modular-wordmarks/` are not approved and should not be used as final brand assets.

After choosing a direction, preserve the ordinary letters as fixed outlines and reconstruct only the approved custom aperture or play-d glyph. Do not auto-trace the entire generated wordmark.
