# Flickday Media

## Brand artwork

Create and revise logos, apparel, watermarks, reusable overlays and brand graphics
in the private `nino-chavez/brand-assets` repository (`tools/brand-assets` under the
workspace root). Read its `AGENTS.md` before creating assets; that file owns naming,
versioning and cleanup. If the checkout is missing, obtain it before design work.

This repo owns website code and deployed copies of selected exports. Record the
library's export path/version when updating a copy. Read `BRAND-PRIORS.md` for the
site's identity decisions. Only `site/` is published; keep agent instructions here
at the repository root.
